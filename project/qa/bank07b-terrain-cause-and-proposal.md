# Bank07失败后的只读地形诊断与单一候选提案

**当前状态：DIAGNOSIS_ACCEPTED_FOR_BOUNDED_CANDIDATE / VISUAL_PENDING。** bank07不采用；根任务同意以下诊断与C级范围后，已用独立helper完成候选，实际结果见 `qa/near-terrain07b-review.md`。以下保留修改前的因果与提案量级，不能代替最终读回数值。根任务完整07仍使用冻结v3核心且无Bank；site.py、site.json和bank_detail.py在本轮保持稳定，没有渲染。

作者实际打开了 `renders/previews/iteration07-bank-cover` 中HERO、Living A、Loggia B三图，以及HABS `data/photo_refs/main_sw_87.jpg`、`main_east_88.jpg`、`data/site-02-review.jpg` 和现有 `assets/textures/forrest_ground_01_diff_2k.jpg`。三张bank图的问题与根任务判断一致。

## 成因来自何处

`scripts/site.py::_height` 没有读取等高线或测量点。近区基底为 `0.10 + 0.205*max(y,0) + 0.035*max(abs(x)-14,0)` 加四组正弦/余弦起伏，北向底坡约每米升0.205m；其后依次应用：

1. 最近河流线段给定水位减约0.53m生成河床；河岸外固定 **5.5m** 用 `t²(3−2t)` 回接背景高程。每条邻近岸都因此获得零坡率两端和中部陡坡的同类S形剖面。
2. 瀑布核心范围另作降土切除。本报告两条重点剖面上的主要凸丘成因不是此项；本项和v3岩台将继续冻结。
3. 各矩形建筑包络内部压至ground_cap，外侧固定 **3.2m** 再用同一smoothstep恢复背景。重复包络顺序取低，没有测量意义的坡顶线输入。
4. 路线半宽的1.4倍走廊采用四次曲线压/抬至路径高程−70mm；最后建筑内再取一次cap。因此保留高背景的狭窄余地可能被两侧压低，形成岛状圆肩。

`_terrain` 在近区用 **0.65m** XY网格、每格固定同向对角线构造三角形，全部216,482面平滑着色。它未生成真实地质坡折/局部沟槽；低频公式与平滑法线保留了连续鼓起外观。细分本身不会消除错误宏观剖面。

## 材质与覆层失败原因

原terrain实际材质槽为 `FW_Continuous_Forest_Floor`，主BSDF确实连接了现有CC0图像链：`forrest_ground_01`、Object坐标Scale0.5即2m纹理宽、BOX投射、Diffuse乘色(0.85,0.92,0.80)、Rough图像映射、Displacement图像进入Bump(Strength0.5,Distance0.045m)。不能诊断为缺贴图；前面的程序ColorRamp已不是当前Base Color来源。

实际打开源图可见青草/苔藓占比高，间有细枝和少量碎叶。用这张源图铺满陡坡，再把2m细节缩到远景像素，仍会读成浅灰绿色均质草土。bank07复制同材质并压成棕色的276个独立三角面，几何边界/随机缺面没有颜色透明渐变，故Loggia B清楚露出polygon贴片。12个独立叶簇既未改变原宏观坡形，也不提供连续林下地表。

## 参考资料能约束什么

HABS02这份场地图可见建筑、桥、路径、Bear Run及植被符号，图上注明道路、路径、Bear Run位置为近似；没有可读的带高程等高线网，也未向当前程序输入等高线。它不能证明4m土丘的精确坡顶坐标。

87照片支持主跌水附近裸露分层岩体与林下植被相接；88照片支持桥/侧廊附近岩岸、深色地表及林下层。它们没有让人可据此标定被遮挡土坡的米制断面。`research/interiors.md` §6支持落叶林、铁杉林、杜鹃等林下形态类型。因此可修正已证实由公式自动生成的规则凸肩，但任何新坡折、凹槽和密度仍须标 **C级作者近似**，不能把“看照片合理”提升为实测地形。

## 单一候选：受约束的近岸坡面与连续地表

根任务读过提案后已授权一版独立候选；实际helper名为 `near_terrain_detail.py`，没有在site/build脚本插入钩子。下述中线是修改前的量级提案，实际冻结mask削小了可移动范围，最终值在读回报告中。

**几何范围。** 保留原terrain对象、XY和拓扑，中心(5,5)的30m半径内，只在两个明确剖面带调整Z：西坡约x−16.5…−8、y−4…3.5；桥北约x23.5…29、y10…17。用作者标明的坡脚/中坡/坡顶折线约束，跨剖面端部归零，不全局替换 `_height` 或全局新增周期噪声。第一版只削低凸肩：西坡最多0.9m、桥北最多1.2m，避免从降土修正变成新增土丘。

**连续地表。** 不创建任何抬高的polygon底层。只复制terrain自身材质，在同一表面以连续权重混入棕灰有机基底；主30m内适用林下区域保持连续，外缘5m渐变归零，河床/核心/路径/楼板权重为零。保留原图真实细粒信息，降低饱和度、削弱草绿色，粗糙度保持约0.85…0.98；它只是作者近似基底，不能把原稀草图称为已验证落叶扫描。

真实薄叶直接铺在同一个实际terrain BVH上，在所有可用干岸连续按面面积采样，设固定非零密度下限和缓慢空间变化，不采用12个圆簇。先以250…400片/m²、叶长6.5…16cm、最多100,000片为有界预算；统计实际面积覆盖和遮挡再判定，避免用总片数宣称足够。对陡坡降低密度并保留原已存在露头，不用均匀碎石或无限加树遮丑。第一版不增加蕨类数量。材质与叶片的共同渐变只能减少边界显现，仍必须实际渲染验收。

## 冻结边界与验证门槛

- v3 core/两个shoulder的三项世界几何哈希严格不变；其他岩体原则上不动，若削土暴露旧岩体悬空则拒绝该局部修改，不能偷偷平移它。
- 原河床及岸线外安全带、水位、所有水对象不变；`main_plunge_and_stair`、resolved主/客房地板包络、桥、全部path中心和侧向安全带不变。
- 所有已存在摄影/导航相机的地面支撑邻域至少2m保持原Z；相机、曝光、灯光不动。核心、河床、建筑/path冻结mask优先于提议剖面。
- 只允许terrain指定Z、受影响植被的贴地Z、为同面地表新增的材质/叶片改变；记录原对象差异白名单，其余对象零变更。
- 核对完整路径采样的地面接触、门洞/头顶安全及桥路接缝；不能仅以顶点在排除框外宣称导航通过。
- 受影响树干及配对树叶以实际新BVH重新贴地，同时重新验证附近所有树根/灌丛/旧groundcover，不能把 `_height` 公式值当贴地值。遇到聚合旧落叶/苔藓只改影响区对应顶点，保留非影响区。
- 接触量测包括新增叶片顶点、三角中心/边中点，原植被/岩体是否浮空；既有camera邻域与冻结地形顶点逐点相同。
