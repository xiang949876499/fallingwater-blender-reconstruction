# Water11：源截面、边界与初态的最小分离对照

2026-09-21。设计参数在 [water11-design.json](water11-design.json)。**后续根已完成 S 两臂各12帧唯一烘焙及只读审计：粗格约2.03倍Q，细格仍高56.15%，见 [source-review](water11-source-review.md)。[source-ready](water11-source-ready.md)保留准备和受控入口历史，不能重复启动。P 两臂仍只设计。** 根实际看过 water10 frame24 的 OVERVIEW/FOOT：直线域边、上游断水和短的孤立深色水柱仍明显；这个显示结果不能作为完整瀑布。本代理本轮没有新增看图、烘焙、渲染或生产改动。

建议下一步优先做更便宜的 **S 源对照**；**P 池体对照**是另一项可独立授权的小实验。它们分别需要两臂才能比较，不是四次连续调参循环；任一结果未定都在固定帧数结束，不自动追加。全连续水体的设计见文末，不能用这两个局部对照代替完整模型。

## 为什么必须分开

水束固定窗口原生 Q 中位数 0.621349m³/s，约为作者 0.299414 的 2.07 倍；原生 phi 湿截面也约两倍。因此先要分辨源离散/求解过流面积与网格重建外观，不能只调玻璃材质或网格半径。另一方面，X+ 删除界面代理在 frame1→48 排出约 2.790m³；该岩下槽在域外真实模型中逐渐封闭，这个开放面不是已证实的天然出口。

作者初池 114.437593m³，而首帧网格 137.184452m³，差 +19.877%。**首帧已推进约 1/24 秒**，所以现有数据并未证明这全部是“初始化膨胀”。可能同时包含离散表示、首步推进、边界和网格重建；不把假设写成原因。依据见 [原始审计](water10-native-review.md)。

## S：同一个真实源，约 3 格与 6 格厚度

保留 water10 实际 360 顶点/716 三角形的源，0.24×0.23m、闭合体积 0.01458765m³，法截面积 0.04317591m²；原世界速度 (-1.503143, -1.005273, -6.694818)m/s、surface_distance=0、velocity_factor/normal/random=0、subframes=1 均不改。两臂均无初池、无冲击、无 secondary，gravity 与稳定09主物理保持，fps24、frame1–12、CPU4（根后续指定；P仍CPU8）。

局部空气域约 **1.8×1.8×1.425m**，名义 X[−0.25,1.55]、Y[−3.0625,−1.2625]、Z[−6.1375,−4.7125]。实际用 water10 求解格原点加 [210,186,21] 个粗格定位，避免缩域改变源相对于网格的位置。六面开放是这个无池自由射流控制的数值条件，不是最终河流边界。最低测量面距几何出口约 6.1 个粗格。

| 臂 | 格距 | 预计真实格数 | 源厚度 | 唯一臂间改变 |
|---|---:|---:|---:|---|
| S24 | 7.5cm | 24×24×19 = 10,944 | 3.07 格 | 空间分辨率 |
| S48 | 3.75cm | 48×48×38 = 87,552 | 6.13 格 | 空间分辨率 |

不能复制一团空域后称“真实岩床不影响”。准备时取冻结场景在域及0.30m邻圈内的实际岩体；实际保留完整连续地形与核心岩两个闭合碰撞副本，其余44个碰撞体的包围盒完全在邻圈之外。新源与两岩体零三角相交，源采样最小净空0.937m、源末端重力位移样本最小净空0.373m。具体哈希、排除清单和采样限制见准备报告；这不是未知液体运动全程无碰岩的证明。没有删除真岩来得到通道。

每帧读独立的 phi 湿面积、原生网格闭合轮廓、MAC 速度/Q、粒子包络/计数和体积；在源内 z−5.35、源下 z−5.58/−5.64/−5.68 测量。源法截面和水平截面的解析面积分别计算，不能把法面积直接当水平面积。每份缓存根据实际 T/dt、格距和源内速度确认单位，不通用硬乘 2.5。记录实际子步/CFL，防止分辨率变化被未达到的时间步上限混淆。

预先定义解释：

- 粗格局部 Q 若不在 water10 水束中位数的 ±20% 内，则没有复现旧现象；池面压力、边界或时间耦合仍可能参与，不能归因为源栅格化单一问题。
- phi/Q 仍过大而网格也粗大，则“只是网格外观”被否定；若 phi/Q 近设计而只有网格膨胀，才支持优先检查重建半径/表面表示。此对照不改半径。
- finer 仅当 frame5–12 都已过启动、各面有水，才比较时序。拟议工程筛查目标为 Q 偏作者 ≤10%、三平面差 ≤5%、时间变异系数 ≤5%。这些是新诊断预设，不是追改旧 FAIL 或改写 PRD。未满足便保留 FAIL/未定，不能自动把源做窄、改 Q 或追加帧。

这对控制仍不能证明 .2994 是现场真实流量，也不能证明自然跌水的全部供给。它只告诉我们同一作者源在粗细两格尺度下如何成为原生过流截面。

## P：同池同床，闭边与原开边各 12 帧

冻结完整 water10 初池、46 个碰撞体、域/格相位、原作者坡折及所有岩下洞，不改任何水位、网格半径或真实床。分辨率仍 **320×307×37、7.5cm**；两臂都关闭入射源和全部 secondary，保留 GEOMETRY 初池零初速。稳定主物理、mesh scale1/radius1.25、fps24、steps1–8 相同。

| 臂 | X−、Y−、X+ | 其余条件 |
|---|---|---|
| Pclosed | 三个实际域盒面设 closed | Y+、底 closed，顶 open |
| Popen | 三面保持 water10 open | 与 Pclosed 相同 |

臂间唯一 RNA 改变是 left/front/right collision border。人工闭合的是明确的诊断盒边界，**不新增伪造岩墙，不作为生产河岸**。边界层 flags/压力随之改变属于这一个边界处理干预；不能再声称把“删除”与“压力”分别隔离。源关闭是两臂共有的控制条件，因此旧有源 water10 不是 Popen 的替代样本，旧09的小池也不能替代 Pclosed。

12 帧已经有可检测的信号：现有 water10 frame1→12 网格变化 −2.802410m³/−2.04%，开放面代理积分 3.294834m³、源下积分 0.268485m³；到第8帧也已下降 1.797824m³。选择12帧保留更多样点，没有理由默认重做24/48帧。此半秒筛查不能证明长期稳态。

同时保存全域与同一内部控制体的作者体积、原生网格/phi/Fluid 格表示，内部体用旧删除界面以内区域，两臂完全相同，避免外层格类型不同被静默混在比较中。每帧保留 9/88 观察点、440 坡折点的所有原始交点/法线列，三种单边湿面积代理及体积差分：

`D(t) = [Vopen(t)−Vopen(1)] − [Vclosed(t)−Vclosed(1)]`。

| 结果 | 能支持的解释 |
|---|---|
| 两臂首帧均偏大；闭池后续稳定，开池下降 | 共同的首帧偏差加开放条件的额外排水 |
| 闭池自身也明显减容 | 仅用开放边界解释下降被否定；初态松弛/表示变化仍需查 |
| 两臂首帧就明显不同 | 边界已影响初始化或首步，不能把 +19.9% 称作独立初始表示误差 |
| 差分信号不足 | 本窗口未定，不自动延长 |

预设关注线为作者→首帧误差5%、闭池原始动态漂移0.5%、开闭变化差0.5m³；它们只用于发现显著问题，**不采用“漂移≤3%即通过”**，否则会吞掉待分辨的约2%效应。D 也不是精确删除质量，更不能由两臂分摊每个出口贡献。

真正 t0 的补证可选但尚未实现：在单独生成的 Mantaflow 脚本中，初池离散化后、首次 advection/pressure/outflow deletion 前只序列化 phi/flags/粒子和时基。需要先确认本机生成脚本与唯一插入点，不改 Blender 安装或求解语句。如果 API 不能支持，就保留“作者→首个已求解帧”的有限解释；不拿 frame0、极小 time_scale 或事后重建网格冒充 t0，也不为找插入点扩展成引擎改造。

P 单臂按 water10 实测 592.585秒/48帧、2.451GB 线性点估 **148.146秒/0.613GB**；旧96真实床24帧16.295秒按格数缩放仅作较低参照。S 的格数线性会给出不现实的亚秒/几秒值，故加入启动、稀疏网格和高速源子步成本；旧 factory32/12帧 CPU4 实测2.589秒只是启动量级依据。表中均为估算，未运行新实验。S 两臂上限180秒，P 两臂上限900秒，授权按族分开，不自动串跑。

准备/复开须核源与岩床世界几何哈希、准确格尺寸/相位、同臂参数、实际 secondary 关闭（仅值不同才赋值）、新缓存独立路径与资源。P 每臂前至少12GB可用RAM、3GB可用磁盘；单臂缓存超过1.5GB止，S超过512MB止。发生参数不一致、碰岩前检不符、CRC/NaN/非法网格或资源/时限失败，停止该臂并保存日志、完整帧及 partial，不重启、不删旧缓存。若一臂未完成则配对结果可能未定。

## 最终连续水体怎么接，仍有哪些条件未满足

**保留并完成上游、下游水体，不能靠关闭它们来美化落点。** 建议继续采用一体化厚水体加局部 native 的混合方法，完整视角展示所有接头；不用全宽处处湿，也不强制整条河 Mantaflow。

1. **从上游供流确定水束。** 使用真实 v3 岩缝和原程序河顶建立床约束的闭合薄水体；平台上游水位固定，原测仅约5cm干舷，不抬全上游。由可湿截面积与合理 C 速度定义各分支 Q，再要求原生源与之匹配。当前 .6213 不能自动变成新接受值；此前 .2994 单束方案仍需测试，全部分支的总 Q 另算。允许真实露岩和不等宽支流，不把粗椭圆硬塞到唇部。
2. **连续通过唇、岩面和跌落。** 水束是有厚度、连续体积的非规则分支，轨迹与重力/接触一致；裁减水体以贴真实岩，冻结岩本身不动。hybrid07a 的静态闭合接头提供方法证据，原 .1017 Q、光滑布状外观、旧动画都不能直接沿用为新通过结果。局部几何需重新满足面积×速度、岩碰撞和上游头高。
3. **在供水区内接 native，而非保留漂浮短柱。** 候选接口选源内部约 z−5.35 的横流截面，实际要先测各帧 native 闭合轮廓。显示派生网格保留其下 native，作者分支以上用同一圈共享顶点与有限厚度过渡连接；消除内部重复封帽，确保整个水体连通。接口可以随真实轮廓变化，但不得每帧选择性删坏面或贴透明/平面盖口。找不到全帧可用轮廓时就保留 JOIN 未通过，不能只裁掉相机上段。
4. **池岸与出流必须具有真实连续几何。** X+ 可检查沿冻结模型从 x8 延至 x14–16，直到整个连通湿区在真实干/实体剖面内结束；既有 x12/14 的稀疏干点还不足以证明整段封闭。不能把 x8 岩下槽随意封成河岸。X−/Y− 的数值出口放到实际河道延续与接合区之外，不让矩形域边成为显示水体终点。未知水下床补体只能在不改变可见岩/岸/建筑的前提下，以有厚度闭合 C 几何明示，不造侧墙截断真缝。
5. **原生池接完整下游。** 在稳定的真实浅水段，用 native 的实际轮廓与下游厚水体建立共享顶点的约0.3–0.6m过渡，保留自然岸线和露岩孔；同一水材质、连续法线与运动。该带之外的 native 主池位置不改，报告派生体与 raw 的体积/表面积差。数值域再多留10–20格缓冲；缓冲不等于压力隔离，仍须原始收支/头高证明。不能把模拟下降强行拉回固定程序池或用第二平面遮缝。
6. **先解决可维持的池面再做长片。** 当前作者主池头高与下游坡折并非已测平衡水面。以选定供流和真实床确定可维持的 C 水面/出流，保留其对露岩、岸线和落点高度的影响记录；不以减体积比例缩放初池，也不去漂移伪造 native 稳态。若真实地形在此 Q 下会排成更低池面，应如实呈现并调整连续水束终点，而不是维持任意高池水位。

每帧必须检查闭合连通、共用接边、厚度、渲染三角形穿岩/自交、坡向/水位/通量、法线与运动，以及不存在固定窄补丁/白泡沫圆片。HERO、FOOT、上游、各岸/出口及绕行视角都要实看；**不能用取景范围代替接合证据**。先由根批准有限预览后，才讨论需要的预热与真实10秒缓存/动画；此次12帧设计与现有48帧都不构成长时通过。
