## 一个上游真实源，供给所有跌水支流

新原生源放在上游较深、流向近水平的河段，候选中心约(15,0.36)，头高沿原 `river_path` 约−2.869m，不再从半空 z−5.35处插入补水。源由**真实河床、两岸与现有水位剖切出的闭合三维体**构成，沿流长度0.6–0.9m；源底不穿岩，顶面不抬高原上游河面。真实湿横断面必须有至少0.225m厚的连续供流部分，才能满足7.5cm格距下至少3格。若实际岩床没有这块净空，就停在几何门槛；不挖冻岩、不抬平台水位、不把薄源称作充分分辨。

新源总量先用 **C作者设计 Q₀=0.40m³/s** 作为一份可视候选的起点，速度由预检得到的真实湿截面 A 定义为 Q₀/A，方向取当地河轴下游切向。具体A和速度必须写入准备报告；不假用旧单束速度6.94m/s。0.40是新整体水形设计量，不是现场测量，也不是把 water10 的0.2994目标或0.6213实流量改名洗成通过。

## 完整可见几何与接边，先交一个可实际查看的候选

候选名称建议 `Fallingwater_water12_complete_geometry01.blend`，先做一份，不自动生成大量变体。全可见河面从现有上游延伸经过近场、全部跌落区域、冲击池，再连接现有约1km下游河道；新原生盒子只覆盖中间近场。

1. 上游河床/水位保持原场景记录。用原真实水体轮廓确定两岸、水中露岩孔与桥/平台邻接；源几何不是渲染物体。闭合水体在真实岸线收边，有实际底面和侧壁，不能用单面片遮域口。
2. 唇到冲击区是与上下游共用边界顶点的分支体积网络。每支根据实际岩隙、下降距离和局部通量形成厚度与宽度，薄片的边缘卷曲/破碎保留连续可追踪的水路。允许露岩和真实断裂水滴，不允许用随机删四边形生成穿透洞。
3. 下游池体按实际 bed/shore 生成连通体，保留岩岛孔；不复制旧矩形水池边，不将池底截成只有5cm的浅盒。不回退 v3 岩层为旧台阶几何。
4. 原生缓存产生后，采用**单份渲染水体的替换区**：池内与主要冲击体取 native 几何；外河段和薄支流为作者几何。沿真实相交轮廓抽取闭环，重建过渡体并共用连接环顶点。旧程序河面在替换区域切除；不存在 native 与程序两层重叠水面。
5. 上游接边候选放在 x≈14–15m的平缓湿剖面，下游接边放在实际完整河道中的 x≈−28至−29m及其斜向下游轮廓，不能直接用AABB整条直边作为水面边。接环随真实缓存头高/轮廓更新，外部作者水体以1–2m的有厚度过渡体连续接入，原始缓存不做去漂移/低通。若不得不造上游逆坡或抬平台水位才能接上，候选失败。
6. 过渡体在每帧标记 native/derived/author 顶点来源，记录相对原生边界的位移、截面面积和体积差。厘米级高频波纹可以C着色表达；深色玻璃布的主体宽度/弯曲要靠几何、真实粗糙尺度、湿岩接触与照明一起检查。喷雾用水材质、合理液滴尺寸和透明路径，不再用密集纯白点；泡沫是薄的、稀疏随流纹理/小团，不用圆片覆盖接口。

几何门槛：闭合体全局边界边/非流形边为0；接环坐标误差报告最大值，不借改阈值隐藏坏点；所有活动三角顶点、边中点与内部采样检查穿岩；法线翻转与局部负厚度均必须保留反例。平台范围不得高于原水位，原约5cm干舷不被上调吃掉。静态初检不等于全帧检查。

根先查看 HERO、WATER_DETAIL/FOOT、上游连接、下游出口四种视域的实际全场景小图。不能通过裁去接头/人工边界让候选通过。只有完整水形具备视觉方向并且源/初态/出口几何门槛通过后，再申请原生长一些的单次运行。

## 首选有限原生域与边界条件

设计盒子 **X[−29,16]、Y[−28,6]、Z[−8.3,−2.4]m**，45×34×5.9m；`resolution_max=600`，目标格距0.075m，预期 **600×454×79=21,519,600格**。这是待实际config验证的格数，未运行时不以RNA零值假称已测。上边有约0.47m空气余量；域不含整场森林或全1km河道。

这里不能沿用 water10 的碰撞副本：其部分 terrain 壳仅覆盖 x≤9.15m。必须从完整源重新提取覆盖新盒子及至少4格外圈的真实地形/岩岸，闭壳底面在真实池床下至少4格；开放沟槽和露岩孔不填堵。对原网格未覆盖的水下区域，只有单独标C的有厚度床体候选可以补足，且不得移动冻结可见岩岸/建筑。覆盖缺口若在可见水底，先展示并审查。

**尾水方案选定为一个C外河段水头条件，不伪称已找到天然临界跌坎。** 在下游真实河槽内、可见连接之后布置1.0–1.5m长的连通有厚度水量储区，床体沿用真实几何；以现有river_path近(−29,−22)的−6.94m为初始候选头高。储区用显式有体积的补水体维持下方水量、头高上方的出流体接收溢流，所有入/出质量单列账。它是数值外部河段储水边界，不是假岩墙、不是透明遮挡面；外部渲染河体依然完整可见。

该方法的可行性**尚未实际证明**：需在准备时验证体积对象不穿床、目标头高与实际坡度兼容，且补/出流区不会把主要观察池吸成它的形状；必须记录它供回上游的水量，不能把所有native水量都称来自瀑布。若根不接受C尾水储区或它无法形成合理连续水头，则完整原生域暂不可执行；先完成作者连续水体候选，不再启动一个已知错误的开放盒子。

## 初态、预热与停条件

初池不是把旧114.44m³几何按比例放大。源到下游全部真实湿通路同时初始化；利用实际横断面、原上游安全头和明确C尾水头做连续的顺床面/回水曲线，避免 nearest-segment 在坡折处跳头。初始化几何必须完全连通、闭合、无退化面；露岩孔保留，跌落处接触和体积也真实建模。原头高若与新Q不相容，先报告岸线变化和物理矛盾，不能抬整个上游。真实体积与将要体素化的phi近似量分别报告，未测前不编造精确V₀。

主物理从 water09 稳定默认设置出发，`fraction=False`、`delete_in_obstacle=False`、FLIP=.97、adaptive steps1–8，其它实际RNA逐项记录。恢复后的源对照完成前，不承诺把R075用进此大域；任何采用非默认半径须先说明证据与真实床回归缺口。secondary只foam/spray，幂等赋值、保存复开实测；粒子材质和渲染设置另记。

计划只跑 **192帧/24fps：前72帧预热，后120帧提供5秒检查**。不是宣称72帧必达稳定，也不自动扩到10秒或补跑。如果预热末24帧仍有持续水头漂移/明显抽排，就停在诊断失败，不把曲线去趋势后输出影片。

逐完整24帧检测；首次48帧即早停门槛：

- 实际源厚度≥3格、源下实测流量与上游供水截面相容；源上端有连续外河水路。±10%仍保留为设计诊断目标，超出记录失败，但不再为任意Q无限扫参；需要重新设计Q则作为新作者参数和新候选记录。
- 初始几何V₀、f1原生mesh/VDB/FLIP指标分别保留，19.9%一类首帧差不能隐藏在新零点。所有开放面、作者尾水补/出流体通量和瀑布入流分别测量；网格体积并非精确粒子质量，任何无法精确计量项列为未证实。
- 9个跌水分区、冲击池9/88个既有观察点以及上下游接环全部有时序记录。无必要全宽每点湿，但每条可见支流必须能追溯到上游，不能漂浮或在相接处无故消失。
- 原始头高持续下降、外域水位反向抽排形成直边、穿岩、越顶、边界明显影响池面，立即停止保留完整帧。预热49–72帧再查水位趋势/收支；后120帧逐帧检查接环法线、厚度和岩接触，根再看实际低清时序。
