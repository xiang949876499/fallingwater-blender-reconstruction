# Fallingwater Blender Reconstruction

This repository contains the current editable Fallingwater reconstruction checkpoint, bounded water and understory candidates, build scripts, source metadata, and QA evidence.

The project is still under visual and interactive QA. The main checkpoint passed the saved-route and camera geometry checks, while final water appearance, complete room photography, GUI navigation, performance, film output, and portability remain explicitly open in `project/STATUS.md`.

Open `project/scene/Fallingwater_integration_candidate12a.blend` in Blender 5.2.1 LTS. Units are metres. The other two `.blend` files are independent candidates and are not silently installed into the main checkpoint.
